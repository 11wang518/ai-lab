## 二、怎么启动（两步）

1. **确认 Ollama 在运行**（右下角托盘有图标；没有就双击 Ollama 启动）
2. **双击项目根目录的 `start-server.cmd`**

窗口里会打印检测权重和访问地址，看到这行就说明好了：

```
[ai-lab] 服务已启动: http://127.0.0.1:8000
```

然后浏览器打开 <http://127.0.0.1:8000/>。

> 不想用脚本，也可以在项目目录执行同样的命令：
> ```
> python run_server.py --provider ollama --model qwen2.5:1.5b --vision-backend ultralytics --vision-weights runs\train\coco8-ft\weights\best.pt --vision-conf 0.45
> ```

## 四、怎么讲（三个层次，按时间选）

### 1. 一句话总览

> 本地部署了 Qwen2.5 做对话、自己训练了 YOLO 做检测，用一个 Web 应用把两者串起来；
> 同一套后端还提供 CLI 和桌面形态。主应用零第三方依赖，克隆下来就能跑。

### 2. 两个关键设计（被追问时讲）

**为什么零依赖**：这台机器装不上第三方包（pip 访问不了软件源），
所以主应用只用 Python 标准库写 HTTP 服务和流式输出。好处是别人拿到就能跑。

**检测后端三级降级**：优先本机 ultralytics → 其次远程推理服务 → 都没有就明确返回
"未就绪"，前端降级到浏览器端算法并标注"非 YOLO 结果"。**没有模型就说没有模型，不拿假结果冒充。**

### 3. 讲取舍和踩坑（这部分最能加分）

- **合成数据训出来的模型不能用**：0.995 的 mAP 在真实照片上几乎检不出东西。
  问题出在数据分布，不是超参数——所以换成真实 COCO8 微调，25 秒就解决了。
- **指标好看不等于能用**：30 轮的版本 mAP50 有 0.888，但置信度只有 0.1，
  实际检不出东西；加到 100 轮才正常。
- **Windows 上端口能被重复绑定**：`SO_REUSEADDR` 的语义和 Linux 不同，
  导致新旧两个服务同时监听 8000，请求随机落到其中一个——这正是"改了参数却不生效"的原因。

## 五、可能被问到的问题

**Q：这个模型是你训练的吗？**
A：检测模型是我们自己训练的——用 COCO8 真实数据在 `yolo11n.pt` 基础上微调，
权重在 `runs/train/coco8-ft/weights/best.pt`。对话模型是本地部署的 Qwen2.5（Ollama），
不是我们自己训练的，我们没有训练大模型的算力。

**Q：mAP 0.995 是真的吗？**
A：那是**合成数据集**上的结果，只能证明训练流程跑通，参考价值有限。
真正有意义的是真实数据那轮：COCO8 上 mAP50 0.872。
合成集的指标我保留在文档里，但明确标注了它的局限。

**Q：只有 8 张图训练，效果能好吗？**
A：不好。所以我是用预训练权重做微调，不是从零训练；
而且文档里写清了"能认"和"好用"的区别——要更好得把数据扩到几百上千张。

**Q：用了哪些开源库？有没有自己造轮子？**
A：训练和推理用 ultralytics，取帧用 OpenCV，模型服务用 Ollama，
Web 服务用 Python 标准库。**没有自研检测算法**，都是站在成熟库上做集成。

**Q：为什么用 Ollama，不用 llama.cpp？**
A：Ollama 装完就能用、自带 HTTP 接口，开发成本最低；
llama.cpp 更轻但参数要自己调。应用层是解耦的，
llama.cpp / LM Studio / 甚至云端接口都能通过改一个环境变量切过去。

**Q：如果给你更多时间，下一步做什么？**
A：三件事——把真实数据集扩到几百张重训、做 ONNX 导出对比推理速度、
再加一个多路视频并发的压测。

## 六、必须如实说明的两点

这两条主动说出来，比被问出来好：

1. **应用的检测模型是 COCO8 微调的**（只有 4 张训练图），
   置信度比官方预训练模型略低。它是"能认"，还不是"好用"。
2. **网页摄像头实时检测这一环，我本机没能自动化验证**——
   无头浏览器不支持摄像头采集。代码和接口都测过，但真实摄像头下的表现需要现场确认。

## 七、出问题时的备选方案

| 情况 | 怎么办 |
| --- | --- |
| 摄像头打不开 | 点"示例图"，用真实照片演示，结果一样是真的 |
| 网页打不开 | 看 `start-server.cmd` 窗口里的报错；端口被占用时脚本会自动换端口，注意看打印的地址 |

| 想展示训练过程 | 打开 `runs/train/coco8-ft/results.png`（损失和指标曲线） |
| 想展示实时推理性能 | 终端执行 `python yolo\realtime.py --weights runs\train\coco8-ft\weights\best.pt --source runs\test-realtime.mp4 --no-show` |
